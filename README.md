# The Simulation Bottleneck of Reinforcement Learning

LaTeX source for the PhD thesis *The Simulation Bottleneck of Reinforcement Learning* by Samuel Garcin, submitted to the University of Edinburgh.

## Template provenance

This repository uses a modified version of the
[`edengths`](https://github.com/H0R5E/edengths) unofficial University of
Edinburgh LaTeX2e thesis template.

The original template incorporates work by George Taylor, Mike Nolta, Mathew
Topper, Eoghan Maguire, and Bill Edwards. The template was modified and adapted
for this thesis by Samuel Garcin.
