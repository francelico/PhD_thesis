# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A LaTeX PhD thesis — *The Simulation Bottleneck of Reinforcement Learning* by Samuel Garcin (University of Edinburgh, 2026). It is built on the unofficial Edinburgh `edengths` thesis template (GNU GPL). The repository was seeded from an Overleaf export ("Initial Overleaf Import").

## Building

There is no Makefile or `latexmkrc`; the project is compiled the standard LaTeX way (and on Overleaf, where it originated). The master driver is `edengths.tex` and the output PDF is `edengths.pdf`.

```sh
# Bibliography uses apacite (bibtex, not biber)
latexmk -pdf edengths.tex
# or manually:
pdflatex edengths && bibtex edengths && pdflatex edengths && pdflatex edengths
```

To compile a subset while drafting, uncomment and edit the `\includeonly{...}` line in `edengths.tex`.

## Structure

- `edengths.tex` — master driver: document class options, title/author metadata, the `\include` list of chapters, and the bibliography call. **This is the file that controls what gets compiled.**
- `edengths.cls` — the template class file (upstream `edengths`). Avoid editing unless changing template behaviour.
- `edengfmt.tex` — formatting: page geometry, headers/footers, ToC, line spacing, **and the `hyperref` PDF metadata (`pdftitle`/`pdfauthor`) which must be kept in sync with the title block in `edengths.tex`** when the `hyper` option is active.
- `packages.tex` — user package imports (loaded automatically by the class). Many common packages are already provided by the class — see the list at the top of this file before adding one.
- `defintns.tex` — user-defined macros (`\input` by the driver).
- `bib/edengref_combined.bib` — the bibliography actually compiled (thesis entries + the three papers' merged `.bib`s; generated by `tools/merge_bib.py`). `bib/edengref.bib` holds the hand-curated thesis-only entries. Citation style is `apacite` (`\citep`, APA-style, surname-first).
- `front/` — front matter (`frontmtr.tex`, pre-content title page in `precntnt.tex`, Edinburgh crest images).
- `introduction/`, `conclusions/` — framing chapters authored directly in this repo.

## Chapter model (important)

Each research chapter lives in its own directory and is included via its `preamble.tex`:

- `chapter2_deac/` — Information Specialisation in Learned Representations of Actor-Critic Algorithms
- `chapter3_dred/` — Data-Regularised Environment Design (DRED)
- `chapter4_persist/` — Learning World Models with Persistent Environment Representations (PERSIST)

The `preamble.tex` in each is a `\chapter{...}` heading plus a "Preamble" section that summarises the work, then `\input`s the published paper (now integrated as native thesis source — see below). Each chapter maps to one of the thesis's three "simulation bottleneck" conditions (representations/overfitting → chapter 2, scenario diversity → chapter 3, simulator existence → chapter 4); preserve this narrative framing when editing preambles.

To add a chapter, place its content under a new directory and add an `\include{<dir>/<file>}` to the body of `edengths.tex` in reading order.

### Thesis by publication (native source integration)

The three research chapters embed their published papers as **native thesis source** rendered in the thesis's own single-column format (one coherent document), *not* as standalone-compiled PDFs. Each paper's `chapterN_*/paper/main_text.tex` (and `supplementary.tex` for ch2/ch3) has been **transformed in place** to a thesis-includable body; the chapter's `preamble.tex` ends with `\clearpage` + `\input{chapterN_*/paper/main_text}`.

Shared support (loaded once from the driver, after `\input{defintns}`):

- **`papers_support.tex`** — the union of packages the papers need beyond the class/`packages.tex`, the **one global theorem set** (thmtools `\declaretheorem`; re-declaring per chapter would clash), no-op stubs for conference-only macros (`\icmltitle`, `\printAffiliationsAndNotice`, …), `\Input`/`\Output`-style helpers, and `\input{papers_mathcommands}`. cleveref is loaded **last** here (must come after the class's hyperref).
- **`papers_mathcommands.tex`** — the papers' shared `math_commands.tex` macros (the figure/eq reference helpers were dropped to avoid clobbering the thesis `\eqref`). `\lvl` is `\renewcommand`'d per chapter at the top of each body.
- **TL2026 firstaid fix:** `\RemoveFromHook{package/amsthm/after}[firstaid/aliascounter]` sits at the **top of `packages.tex`** (must run before amsthm loads), with the cleveref counterpart in `papers_support.tex`. Needed because the global theorem set uses `sibling=theorem` (else `\c@lemma already defined` under TeX Live 2026).

Per-chapter transformation (done once; git is the record of the original source):

- Conference preamble, `\twocolumn[...]`/`\maketitle` title block, and `\bibliography*` removed; `\begin{abstract}` → a numbered `\section{Original Abstract}`; `\end{document}` removed.
- The appendix is wrapped in the `appendix` package's `subappendices` environment, giving **per-chapter lettered sections** (2.A, 2.B, … resetting each chapter).
- Each body starts with a per-chapter `\graphicspath` reset (paper figure subdirs aren't on the global path) plus any macros the body used from the stripped preamble.
- **`tools/integrate_paper.py`** performs two mechanical passes: prefixing every `\label`/cross-ref key with `c2:`/`c3:`/`c4:` (the three papers reuse `fig:`/`sec:`/`eq:`/… — prefixing prevents collisions in the merged document), and un-starring full-width floats (`figure*`/`table*` → `figure`/`table`). wrapfigures were unwrapped by hand (size preserved).

**Bibliography:** all paper citations resolve against one combined database, `bib/edengref_combined.bib` (the driver points `\edbibliography` at it; it must stay committed — Overleaf can't run the tools). It was *originally* generated from `bib/edengref.bib` + the three papers' `.bib` files by `tools/merge_bib.py` then `tools/dedup_bib.py` (exact-dup removal, same-work-different-key unification with citation rewrites, conflict flagging).

**⚠️ `bib/edengref_combined.bib` is now hand-curated — do NOT regenerate it with the tools.** After generation it received manual edits: the `%[REF CONFLICT]` `@comment{}` blocks were removed and specific conflict winners were chosen (e.g. `valevski2024diffusionmodelsrealtimegame` is kept as the ICLR `@inproceedings`, not the arXiv version). Re-running `tools/dedup_bib.py --apply` overwrites all of that. Edit `bib/edengref_combined.bib` **directly** for any bibliography change; the `tools/` scripts are kept only as a record of the one-time build.

**Build:** just `latexmk -pdf edengths.tex` (no pre-step). The old `build_papers.sh` / `_thesis_main.tex` / `\includepaper` / `pdfpages` machinery has been removed.

## Template leftovers — not part of the thesis

These come from the upstream template and are **not** compiled by `edengths.tex`. Do not treat them as thesis content:

- `class_examples/` — alternative `.cls` files the template was derived from.
- `template_chapter1/`, `template_chapter2/` — demo chapters.
- `appendix/edengapp.tex`, `appendix/appendx1.tex` — example appendix scaffolding (the appendix `\include`s are commented out in the driver).
- The CI badges and credits in `README.md` describe the upstream `edengths` project, not this thesis.

Note: `\graphicspath` in `edengths.tex` lists the real content directories, so `\includegraphics` resolves figures from any chapter dir without a path prefix; add new directories there when adding chapters.
